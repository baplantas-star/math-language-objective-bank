# Math Language Objective Bank

A lightweight, curriculum-independent language-objective bank for grades 3–5 mathematics.

## What it does

Teachers select a grade, mathematical topic, and lesson focus. The app returns:

- one prescribed primary language objective;
- an optional secondary objective when students evaluate or extend reasoning;
- a visible three-part structure: **Key Language Use → Domain → Language Feature**; and
- explicit language examples students can use.

The bank contains 21 mathematical topics and 67 lesson focuses across grades 3–5.

## Design principles

- **One objective, one language feature.**
- Objectives recur intentionally across related lesson focuses.
- The language objective is treated as an instructional target, not a compliance statement.
- The app is a single self-contained HTML file with no database, account, analytics, or server-side processing.

## Privacy and security

The app does not collect, transmit, retain, or process student information. All interaction occurs locally in the user’s browser.

## Independence

This is an independently developed instructional tool. It is not affiliated with, sponsored by, or endorsed by any curriculum publisher. Topic labels are generic mathematical content categories; the language objectives and examples were independently developed.

## Run locally

Download `index.html` and open it in any modern browser.
